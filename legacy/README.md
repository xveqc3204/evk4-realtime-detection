# Historical terminal prototypes

These are the original acquisition, v0.1 activity, and v0.2 terminal-tracking
scripts. They are preserved without changes to their code. They are not the
current three-flag GUI.

For current work, return to the repository root and use `bash run.sh`.
The current application is `rotor_lab/`. See `../README.md` and `../docs/TESTING.md`.

The old requirements apply only to these historical scripts. Do not install
them over the working GUI environment. `README_original.md` and
`PROJECT_STATUS_original.md` are historical records, not current instructions.

To inspect the original terminal prototype intentionally, use a compatible
environment and run `python legacy/live_activity_v02.py` from the repository
root. Do not run it while another program owns the EVK4.
