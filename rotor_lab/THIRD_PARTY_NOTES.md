# Dependencies and provenance

This revision modifies the EVK4 Rotor Lab application supplied in this conversation. It is a custom burst-onset period estimator with a new experiment UI and export layer. It does not vendor Matthew's repository, Prophesee's proprietary algorithms, FrequencyCam, or any third-party font files.

The launcher installs neuromorphic_drivers, NumPy, Numba, OpenCV, and Matplotlib from their package distributions. Their respective licenses and notices remain with those packages. Dependencies are not embedded in this archive.

The application retains the concepts of direct event access, per-pixel temporal evidence, spatial support, persistence, bounded previews, recording, and explicit uncertainty. The period estimator is not claimed to reproduce an official frequency estimator or to have been validated by its referenced papers.

Reference links are in ALGORITHM.md. No upstream GitHub repository is modified or pushed by this application.
